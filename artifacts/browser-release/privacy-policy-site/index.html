Privacy Policy

GrassEye Browser Authority · Effective 21 August 2026

GrassEye Browser Authority is a browser-side companion for a locally installed GrassEye workbench. It provides a narrow, user-initiated command boundary for one operator-selected browser target. This policy explains how the extension handles information required for that function.

Information the extension handles

Only after an operator selects a browser tab and a permitted command is received from the local companion runtime, the extension can handle the current target's URL, page title, document state, and the specific page content or form text required for that permitted command. It can also handle command-result and error information needed to report whether that command succeeded, failed, or requires review.

The extension is not designed to collect Chrome-wide browsing history, passwords, cookies, session storage, payment details, or data from tabs that the operator has not selected.

How information is used

Information is used only to verify the selected target and to perform the permitted exact-target command requested through the local GrassEye workbench. The extension does not accept free-form browser instructions and does not make autonomous decisions about what the operator should do next.

Sharing and transfers

The extension exchanges the minimum command and result information with the locally installed GrassEye companion host on the same device. It does not include an extension-side HTTP, WebSocket, advertising, sale-of-data, or third-party analytics transport. The extension does not sell or use user data for advertising, profiling, creditworthiness, or lending decisions.

Storage and deletion

The extension does not operate an independent cloud datastore. Any task records, evidence references, or diagnostic logs created by the local GrassEye workbench are retained on the operator's device under that workbench's local data controls. Removing the local workbench data or uninstalling the extension stops the extension from retaining or processing new data.

Security and user control

The extension acts only on an operator-selected target and only after the local runtime supplies a registered, authorized command. It does not bypass sign-in, CAPTCHA, account security, or website controls. You can stop future use at any time by closing the claimed target, disabling the extension, or uninstalling it.

Chrome Web Store Limited Use

GrassEye Browser Authority uses information only as necessary to provide its disclosed single purpose. Its use of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Contact

For privacy questions, contact the publisher through the contact email shown on the extension's Chrome Web Store listing.

Policy updates. If this extension's data practices change, this policy and the Chrome Web Store privacy disclosures will be updated before the changed practice is released.
