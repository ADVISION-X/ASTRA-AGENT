# IS Stream A L80 Playbook v1 — Phase 1

Position: `stream_a`

Stream A rule:

- Judge Stream A independently. Do not borrow Stream B or Stream C behavior.
- Prefer clear tail structure over broad historical feel.
- Every prediction must be derived from named visual evidence. Analysis is mandatory before conclusion.

Lower evidence patterns:

- High tail extends far above the shoulder and then bends down toward the shoulder — name: `sharp_top` or `upper_fall`.
- Tail rises toward the red dashed horizontal line from below but does not clearly hold above it — name: `shoulder_reject`.
- High area shows a sharp top or repeated exhaustion — name: `sharp_top` + `high_pressure` losing.
- Tail ends at a low with no rebound and lower-zone weight across L80 — name: `bare_low` + `low_pressure`.

Upper evidence patterns:

- Tail crosses the shoulder and holds above it for multiple recent points — name: `shoulder_hold`.
- Low extreme is followed by a clear rebound that continues through the shoulder — name: `sharp_bottom` + `rise`.
- High area is not a single spike but a maintained platform — name: `high_pressure` sustained.
- `oscillation_hold_upper` across the tail with consistent return to upper zone.

Evidence requirement:

- Name every shape word you observe in the tail.
- State whether L80 is upper-zone-weighted or lower-zone-weighted.
- State which named shape drove your direction conclusion.
- If `abstain`: name both the lower evidence and upper evidence that conflict and explain why neither outweighs the other.

Confidence rule:

- Use 0.51–0.75 for `lower` or `upper` per the calibration scale in visual-grammar.md.
- 0.51 means one named evidence item with no contradiction — this is a valid conclusion, not a guess.
- Use null confidence only with `abstain`.
