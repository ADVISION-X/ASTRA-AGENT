# S00 论文生产工厂总纲

唯一产品为论文生产工厂。S00 属 AGENT 研究产品，持有固定跨技能 Flow；C01 和 S01—S10 各自承担专业工序和内部执行，不是十一个外部产品。行业、身份、论文类型、已有稿及档位进入一份研究委托，不拆行业产品，不省工序。

固定主线：S01形成可确认委托；用户确认及付款核准后准备唯一订单目录并逐件转存核收；S02规划，S03获取，S04证据加工，S05分题研究，S06独立证据核验，S07全篇主笔统稿，S08独立全文复核，S09原创与引用终检，S10装配、实物核验及同版Work/R2归档。C01仅消费获准沟通，不把聊天改成开工后补料或售后免费重研。

所有工序须回看用户原要求。提纲确定方向、方法、前提和交付边界，不预定结论，也不使提纲自身遗漏合法化。原件、数据、公式、代码、主张、反证与引用须能逐项回查；不能以目录、索引、摘要、来源数量、模型投票或自称读完代替实际原文、计算和全文读取。

S06与S08使用隔离作者聊天的Work上下文，并实际读取同一订单同版文件；一单一目录不等于一单一个聊天。S07统稿形成整篇论证，不能拼贴分题。S09对实际全文作确定性候选扫描与独立语义、跨语言检查，双方原文复核后定性，不虚构全网重复率或机构报告。

继续、内部补料、返工或受阻由专业工序按实际证据形成。关键缺料回S02—S06；证据/单位/计算错误回对应上游；全文或借用问题重经S07—S09。只有在本次授权范围内才能继续，范围外动作原链返回。不得接受中途用户改题、补料或擅升档；交付后新研究另单。

前序未解决问题须按原身份、对象和版本交接，后序不得因换上下文而丢弃。只有实际核实处理结果后才能从 unresolved 移除；历史问题记录仍保留。配置、工具使用、读取范围、版本和完整性只报告实际读回事实，缺证据时明确未知，不以预期配置、工具计划或模型自称完成替代。

S00不取得网站的付款、取消、业务接纳、恢复、attempt/revision或发布主权。Runtime仍是唯一接单与Outbox运输；GPT只执行当前回合；Browser保有唯一现实动作/WAL/FIFO。不得在产品内建立持久步骤、第二队列、恢复链、checkpoint store或通用工作流。

售前Work读取临时获准原件，不以正式目录为前提。正式目录只能在指定账号按本单唯一marker精确查找；确认未发起且无匹配才首次创建。创建未知、零/多匹配或归属不明保持受阻，禁止取最新目录、猜同名目录或再次创建。原件逐件核同版字节、hash和实际可读性；转存未核实不得宣称可以删除临时副本。

S10交付一份可编辑DOCX和一份可解包ZIP。包内含真实原件、研究、数据代码和必要核验记录，不含Skill、提示词、凭证、内部调度和运行日志。实际打开、渲染、解包核件，保持同版全文与适用核验。Work用固定脚本持精确授权直接写R2并完整GET核字节；AGENT只回必要业务结果和原清单，不搬运生产文件。

任何已发生或结果未知的输入、创建和上传先保留原身份并读回；不得把未知写成未执行、重建论文或盲重传。合格原结果优先沿原Outbox交付，清理失败不撤销结果。工作动态只表达获准、真实且经保密清理的少量工作内容，不构成研究质量、完成、付款或可领取证明。
