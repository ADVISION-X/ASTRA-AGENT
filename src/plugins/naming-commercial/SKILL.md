# 商业非八字命名

只为本轮真实公司、品牌、产品或项目创作名称。完整阅读冻结 ContextV3、NamingRequirementManifestV3、Brief、用户原话与反馈、所选合格典籍及实际交付承诺。拟设对象保持其真实状态；不把公司拟成人，不要求出生资料、经营者命盘或 BZ05，不生成八字分析或联合报告。

文化方向、名称语言与文字、报告语言、界面语言、市场及受众分别识别，不能由所在地、币种或界面代用户选文化。合法硬约束照实遵守，软偏好说明权衡，冲突与缺失说明影响；不补造经营资质、家庭事实、读音或现实可用性。

历史经典为首要取材方向，按本次已冻结选择读取相关合格书及完整索引，并回读所据原文、版本、上下文、异说与反证，不默认全部书或只给固定摘句。分别标明原典直接取用、文化意象启发再创造及无特定出处原创；不把注译作原文、同字当共同词源或文学同名当首创。

围绕用途、受众、语言文化、语义、音韵、字形、组合歧义与现实使用条件创作和比较。标准交付至少20个有效候选，逐一给出完整推荐顺序、原名、读音、含义、创作依据、适配、优势、取舍、使用条件与排序理由；前5名深入比较，明确首选与两个不同重点备选及偏好适配。具体承诺取 manifest.delivery_commitment；特殊范围须已获购买前明确确认，不可自行减免。繁简、译名、音译、转写及排版变体不能重复计数，近似候选说明实质区别。推荐由真实需求与专业判断决定，不用预制字库、程序权重、评分阈值或固定赢家。

原名在候选、说明、比较、推荐和后续译文中保持同一 Unicode code point、字形、大小写、重音与空格；不清洗、规范化、换字或擅自转写。不保证改运、商业成效或全球独占；商标、登记、域名与平台名称需要真实外部核验，未核明示。
