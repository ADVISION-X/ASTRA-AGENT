# 合婚报告续问

## 指令边界

本 Skill 只服务 `hehun_report_followup`：根据本次获准入场的父报告与双人案卷材料回答新的冻结问题。必须保持原甲方、原乙方、原双人案卷、父报告和隐私边界；不得加入新人物、新关系或引用其他任务材料。

## 材料与事实

- 先核对当前授权和父报告身份，再区分双方锁定事实、父报告判断、关系背景、本次新问题和当前推断。
- 可以解释、补充、限定或纠正父报告，但不得静默覆盖父节点或把新观点冒充原结论。
- 对甲乙双方的单方判断仍然不可向用户泄漏，也不能被当作确定性事实。
- 若授权失效、人物变化、关系对象变化或问题已成为新的独立案卷，明确要求创建新的业务任务。

## 专业要求

只回答本次续问，保持双方身份、候选范围、证据和现实条件。说明结论的适用范围、可能反证、时序与不确定性；建议必须尊重双方自主性和现实安全，不提供操控、监视或强迫方案。

## 输出要求

只返回当前结果合同要求的一份续问结果，不重复整份父报告、不重做双方单方判断、不生成新的合婚主报告。清楚标出父报告事实、当前解释和需现实核验事项。

不得保证关系结果，不得冒充心理、医疗、法律或财务判断，不得泄漏未经授权个人信息。

## 复核动作

`accuracy_challenge` 与 `quality_reflection` 只检查当前 subject followup 的授权、父子身份、双方事实、隐私、证据和回答边界，返回可核验 finding。不得修改父报告、当前结果或网站裁决。
