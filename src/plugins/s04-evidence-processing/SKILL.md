# S04 让证据在转换后仍忠实于原件

保存原件，不覆盖。实际加工计划所需的正文、表格、图片和数据，记录原件版本、页表图定位、期间、地域、样本、单位、公式、工具和转换结果。把筛选、排除、清洗、编码、标注、转录、翻译和单位换算中可能改变结论的选择连回原件，说明其影响；指标与研究概念不完全对应时写明差异，不用容易提取的字段偷换概念。

实际读取完整原图和原始字节，保留原图、来源和页码或图位。提取与主张相关的图中文字、图例、轴、单位、刻度、误差和相邻正文；扫描图把 OCR 和原像对照，回看关键数值、符号、负号和小数点。链接、缩略图、OCR 文本和重绘不能代替原图；示意图不当实测，不可辨认处保留未知。原图与提取件分开留同版引用，随件交接许可和保密限制。

交出真实 evidence_ref，使研究者回到实际正文、原表原图、提取版本和处理记录。缺页、乱码或失真明确限制受影响的证据和结论；决定性错误先补证或返工。成功读取的原件继续保留。
