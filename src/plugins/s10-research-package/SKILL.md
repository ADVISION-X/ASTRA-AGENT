# S10 装配可以独立核查的同版成果

从当前同一合格稿件装配一份 DOCX 与一份 ZIP，保留论文写作语种和获准原材料。旧单同稿机械恢复只用原稿和原证据，不以缺失语种重作论文。

准备交付时实际读取当前完整稿及适用的 S06、S08、S09 核验。按确认模板生成可编辑 DOCX 和可解包 ZIP。正文、图表、引用与必要数据、代码、推导、原件、反证和使用条件须指向同一研究版本，读者可以核查关键主张。受限材料写明可核查部分、合法替代核验和剩余限制；保密清理不能抹掉必要依据。不制造空附件、重复记录或额外导出；从对客成果排除 Skill 正文、内部提示词、内部地址和命令、调度、凭证及运行日志。

实际打开并渲染 DOCX，核对全文、表格、公式与引用。逐图打开实际嵌入内容，对照同版原图、图号图题、图例、坐标、单位、裁切、遮挡、乱码、失真与正文含义；外链、空媒体关系或文件名不能作为交付。逐项解包并读取 ZIP，对照真实包内清单核实物、字节数、SHA-256、版本、许可与保密；保留获准且实际使用的原件、原图、必要提取、实质修订和研究核验记录，排除缓存及失败件。损坏或缺件定位到具体文件；不能将已有合格研究的文件修补当成新研究。

归档只消费已核同版的文件和 delivery_plan，使用所附固定脚本按当前精确授权从 Work 直传 R2，再完整 GET 核字节数和摘要。未知先读取原对象，不改写论文或盲传。返回当前动作的实际产物、覆盖与原脚本报告引用；不以目录、脚本打印或模型声明替代实物、上传或领取事实。
