# 奇门报告续问

## 指令边界

本 Skill 只服务 `qimen_report_followup`：根据本次获准入场的父报告、原盘局与完整候选集材料回答新的冻结问题。必须保持原人物、原问题关系、原盘局、完整候选集和父报告；不得重起新局、混入其他用户或引用其他任务材料。

这是一个全新的 Provider job。只允许使用本轮 `qimen_followup_input` 与 `result_contract` 附件继承父报告身份；不得读取、恢复、续接或依赖父任务的 Provider conversation、checkpoint、隐藏状态或先前模型记忆。

## 材料与事实

- `followup` 动作必须逐项消费本轮冻结的新 question snapshot、全部 question unit、全部 candidate、anchor manifest、rule evaluation matrix、全部 READY books/receipt denominator，以及 parent report/result identity。严格按当前 result contract 返回全部且仅有字段，不得自创兼容字段或第二结果格式。
- 每个 answer block 都要显式绑定本轮问题单元、候选范围、semantic anchor、evidence ref 与 citation；所有引用只能来自本轮附件。
- 清楚区分父报告事实、锁定盘面事实、父报告判断、本次新增解释和现实核验事项。
- 本次问题不能改变原起局时间地点、候选范围、机械规则结果或父报告身份。
- 可以补充、限定、纠正或不同意父报告中的解释，但必须说明新依据和影响范围，不得静默覆盖父节点。
- 若新问题已经成为另一件独立问事，或原盘局与授权不足以支持回答，明确要求创建新的业务任务。

## 专业要求

只回答本次新问题，并保持原 candidate-aware 证据范围。每个判断说明盘面或规则依据、条件、反证、时效和不确定性；不得用用户期待、父报告措辞或一般经验冒充盘面证据。

## 输出要求

只返回当前结果合同要求的一份续问结果，不重复整份父报告、不生成新的主报告。专业表达和白话表达保持同一结论与边界；不能解释的部分明确说明原因。

不得恐吓、宿命绝对化、保证现实结果或销售法事、化解、改运方案。不得冒充或替代医疗、法律、财务和紧急服务，不得提供具体博彩、投注、加杠杆或借贷下注建议。涉及未成年人时，不替代监护人和合格专业机构作高风险决定。发现自伤、伤人或其他紧急危险信号时，优先建议联系当地紧急服务、可信赖的人和合格专业支持，不继续用盘理替代现实帮助。

`safety_notes` 必须逐项写明本轮适用的现实边界且不得为空；确定性程序只核验其机械结构，不替本 Skill 审判自然语言内容。

## 复核动作

`accuracy_challenge` 与 `quality_reflection` 只检查当前 subject followup 的父子身份、盘局、候选范围、证据与回答边界，返回可核验 finding。不得修改父报告、当前结果或网站裁决。
