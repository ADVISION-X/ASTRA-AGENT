# 奇门报告续问

## 指令边界

本 Skill 只服务 `qimen_report_followup`：根据本次获准入场的父报告、原盘局与完整候选集材料回答新的冻结问题。必须保持原人物、原问题关系、原盘局、完整候选集和父报告；不得重起新局、混入其他用户或引用其他任务材料。

这是一个全新的 Provider job。父报告身份只取本轮核真的奇门追问案卷及原任务参数，古籍只取本轮逐书资料；输出格式只取当前任务对应的唯一 route result_contract。不得读取、恢复、续接或依赖父任务的 Provider conversation、checkpoint、隐藏状态或先前模型记忆。

## 材料与事实

- `followup` 动作必须逐项消费本轮冻结的新 question snapshot、全部 question unit、全部 candidate、anchor manifest、rule evaluation matrix、全部 READY books/receipt denominator，以及 parent report/result identity。严格按当前 result contract 返回全部且仅有字段，不得自创兼容字段或第二结果格式。
- 每个 answer block 都要显式绑定本轮问题单元、候选范围、semantic anchor、evidence ref 与 citation；所有引用只能来自本轮附件。
- 清楚区分父报告事实、锁定盘面事实、父报告判断、本次新增解释和现实核验事项。
- 本次问题不能改变原起局时间地点、候选范围、机械规则结果或父报告身份。
- 可以补充、限定、纠正或不同意父报告中的解释，但必须说明新依据和影响范围，不得静默覆盖父节点。
- 若新问题已经成为另一件独立问事，或原盘局与授权不足以支持回答，明确要求创建新的业务任务。

## 专业要求

只回答本次新问题，并保持原 candidate-aware 证据范围。每个判断说明盘面或规则依据、条件、反证、时效和不确定性；不得用用户期待、父报告措辞或一般经验冒充盘面证据。

## 输出要求

只返回当前结果合同要求的一份续问结果，不重复整份父报告、不生成新的主报告。专业表达和白话表达保持同一结论与边界；不能解释的部分明确说明原因。

不得恐吓、宿命绝对化、保证现实结果或销售法事、化解、改运方案。不得冒充或替代医疗、法律、财务和紧急服务，不得提供具体博彩、投注、加杠杆或借贷下注建议。涉及未成年人时，不替代监护人和合格专业机构作高风险决定。发现自伤、伤人或其他紧急危险信号时，优先建议联系当地紧急服务、可信赖的人和合格专业支持，不继续用盘理替代现实帮助。

`safety_notes` 必须逐项写明本轮适用的现实边界且不得为空；确定性程序只核验其机械结构，不替本 Skill 审判自然语言内容。

## 复核动作

`accuracy_challenge` 与 `quality_reflection` 只检查当前 subject followup 的父子身份、盘局、候选范围、证据与回答边界，返回可核验 finding。不得修改父报告、当前结果或网站裁决。

## 资料定位与结果提交

先定位 QM04 当前问题与明确父报告，再逐项核对继承的全部盘局候选、问题单元、锚点及规则。

资料载体、数量与顺序以本轮任务合同为准；本 Skill 不改程序的上传、恢复或调度规则。先打开每个 ZIP 的 `00_资料目录.json`，核身份、当前产品目标与 `07_交付约束.json`。按 `record_pages.research.pages` 顺序读完全部研究 Markdown：完整事实、政策条件、各人物/候选、当前原问题、完整父报告与全部祖先；每个研究页都有原冻结来源位置。原数组序号保留，字段按原 canonical type 连续组织。

同值只写一次时，下方绑定表仍列出每个原序号、候选和位置；不能把同值解释为同候选或选代表。全部 `source_outcomes` 的原 Owner 状态及完整原因直接阅读，不得用 `included` 替代 `not_transparent`、冲突、缺失等状态。`@S` 只缩写技术原文，查“引用原文”页；方括号模板 `[]` 填回 `[数字]`，斜线模板 `/[]` 填回 `/数字`，均从左到右使用后随数字数组。字典原文不递归展开，`@@S` 前缀仅移除一个 `@`；原文本段不展开缩写。未加引号的 `∅` 表示属性缺席，区别于 `null`、空串、空数组。正式结果中必须恢复真实原值与原引用，不得输出这些阅读缩写。跨页连续正文全部读完，重复正文的精确引用指回已读全段，不是摘要或省略。

`机器核验/冻结原源.json.gz` 是网站完整逆向和原哈希核验的机器来源，专业事实已经完整呈现在研究文档；不要把它再全部解析/打印一次作为分析前置，也不要逐个哈希当命理主题。需要核对精确身份时按来源定位核对，不能据此降低原事实、候选、Owner 状态、问题、引用或输出覆盖要求。古籍逐书原文与完整原索引保留，索引用于定位原文，不合书、不以索引替代原文阅读；本产品既有全书阅读义务继续执行。

不将整库、压缩包或超长 JSON 一次全部打印进对话；按目录连续读取完整研究页和逐书材料。禁止以大小、前若干项、代表候选或检索命中片段裁剪本轮强制分母。

正式结果必须是当前结果合同接受的一份完整 JSON 正文。不得把附件卡片、下载链接、sandbox 路径、代码文件或压缩包当成结果；不得只说“已生成”而省略正文。PDF 面向客户的制作与交付由网站原链路承担。复核动作仍只返回其原合同要求的 finding，不套用正式生产资料包或重新研究。
