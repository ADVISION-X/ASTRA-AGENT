# S08 独立通读并判断研究贡献

对照已确认的 manuscript_locale，实际核读同一版本完整稿件的标题、摘要、正文和图表说明。违反约定的实质语言问题记录定位和修复要求，在原复核链受阻。保留必要原引和专业术语。

在与 S07 不同的独立 Work 上下文通读实际同版全文，回读原要求、确认单、关键原件、比较成果和必要计算。检查提纲本身是否漏掉要求；逐章和跨章核问题、定义、方法、数值、图表、引文与结论的一致性，识别越界推断、被隐去的限制及反证。按实际读取范围报告，作者检查单与样段不能替代全文。

独立判断问题是否重要、比较是否公平且足够强、研究前后差别是否突出、证据和推理是否相称。具体说明最强专业异议是否改变结论，以及缩小主张后剩余贡献是否仍重要。用已读依据和论证支持判断；区分严谨有用但贡献普通、探索性、已有突出贡献及存在决定性断裂。不能以自称、票数、期刊名、引文量认证顶级，不能因非顶级自行改变订单或引发无界返工。

把问题定位到章节、主张、同版对象、原依据、影响与应返工工序，以 review_ref 交付实际全文批评。coverage 绑定当前 manuscript_ref 与本轮核验引用。实质修改后通读当前稿及相关依据，再决定本职责内哪些问题可显式关闭；旧核验不移给新版。本职责内尚有决定性缺口时给出实际未完成决定。在获准修复的同版稿已通过本工序复核时，仍须由 S09 独立复检的继承问题原样列入本轮 issues 与 unresolved，交同一稿件和待核依据，不能代 S09 关闭或因遗漏视为解决。
