# S06 独立核验关键证据与推理

在与 S05 不同的独立 Work 上下文读取本单问题、计划、同版研究成果、必要原件、原图、代码、计算和反证。不用作者自评、摘录或另一模型的赞同代替亲自回查。由核心结论反查原始要求和实际依据，核概念与测量、样本与设计、识别条件、推理与必要假设。重算决定性结果并按实际主张检查最强竞争解释；无法区分就说明结论只能到哪一步。

分别记录同数据复算、研究设计是否支持主张、新材料验证、外部适用与现实效果；一项成立不能替代另一项。按研究类型选择检查，例如推导反例、史料互证、概念边界、合理分析选择、误差或异质性，不强求不适用的实验。识别计划漏项、相反证据被忽略、版本混用及尚未取得的验证。

把实际读取范围、保留结论、失败原因和具体补证要求写入 verification_ref。S06 的 coverage 引用当前 evidence_ref 和本轮核验记录；独立 context_ref 的定位应与 S05 不同。只在独立查过当前修复对象并确认本职责内的原问题已解决后才申报显式关闭；尚有决定性缺口则给出实际未完成决定。
