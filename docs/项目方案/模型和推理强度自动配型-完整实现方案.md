状态：**本轮按授权原位减法施工；AGENT GPT/Browser 施工图、合同、实现与质检同步调整，真实页面及生产业务完成尚未验证**。AGENT 候选为 `main@aa550261c3e6d89c46a0cb224cb66a25329d5e72`；不修改 active law、Website 或数据库，不启动子智能体审查。

唯一业务规则：**技能指定的模型是精确目标，绝不降级或替换；只把技能要求的推理数值向当前已选模型的滑杆上限截断。**

```text
exactModel = 技能现有模型信号
requestedValue = 技能声明的 0..5 整数强度目标
选定 exactModel 后，在当前 Target/Document 读取 slider 的 min/max/now
require min == 0 且 max/now 为有效整数且 0 <= now <= max <= 5
resolvedValue = min(requestedValue, max)
若 now == resolvedValue：点击当前滑块柄一次；否则一次受控键盘动作到 resolvedValue
fresh readback：唯一有效 slider.now == resolvedValue，才继续工单
```

例：要求 `5`、页面 `0–5` → `5`；要求 `5`、页面 `0–4` → `4`；要求 `4`、页面 `0–3` → `3`。页面上限高于要求时不升级。页面不能精确证明指定模型可选，或滑杆/读回不合法，就失败报告，不换模型、不猜 Pro 额度。**数值优先于“Pro/极高”等展示文字**；不能仅凭旧账号徽标、标签或固定档位表重解释授权人的公式。

## 4. 验收、失败与回接

| 场景 | 必须观察的结果 |
|---|---|
| 指定 `GPT-5.6 Sol`，页面也有“最新” | 只选 Sol；Sol 不可用则明确失败，绝不切“最新” |
| 指定“最新”，仅 Sol 可选 | 指定模型不可用，零模型替代、零 Provider submit |
| 要求 5，选定模型的 slider 为 `0..5`、当前任意合法值 | 动作一次；目标 5；读回唯一滑块 `now=5` |
| 要求 5，slider 为 `0..4` | 目标 4；不借标签推断 Pro 可用性 |
| 要求 4，slider 为 `0..3` | 目标 3；不向上、不另选模型 |
| 要求 4，slider 为 `0..5` | 目标仍 4；不得升至 5 |
| G15 后置 opacity hidden；页面子菜单确实可见 / 不可见 | 前者按实际可见模型选项验收；后者保留一次点击的 WAL 事实并失败，不盲点第二次 |
| G16 模型点击未能关闭列表，或 G17 slider 数值无效/读回不等 | typed failure、零 submit；不得把未证实的页面状态拼接为成功 |
| 已发生或结果未明的 Browser 输入 | 沿原 WAL 只读结算；Website 决定旧 attempt 终止、新 attempt 或同 effect 恢复，AGENT 不自签 retry |

先跑最小 GPT/Browser/Product 原生回归及 `quality:check` 对应阶段；动态验收必须分别覆盖 `0..3/0..4/0..5` 和精确模型正反例，特别证明 G15 不再因同类 `OPACITY_HIDDEN` 误拒。最后以最小获准真实工单确认 Browser 后置事实、唯一 submit、Website admission receipt 和领域对象独立 readback；CHANGE/READY、页面点击或 mock 均不等于业务完成。本方案只定义施工与验收，不宣称当前生产已修复。
