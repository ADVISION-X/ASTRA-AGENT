# 种草产品挖掘：一个拥有“眼睛”和“手”的 Agent 故事

## 1. 它诞生的原因

在一台安静运行的电脑里，有一个特别的 Agent。

它不是普通的软件。

普通的软件，只会等待人类点击按钮、输入命令、上传文件，然后机械地执行任务。

但这个 Agent 不一样。

它像是拥有了一双“眼睛”，也像是拥有了一双“手”。

它可以打开浏览器，可以输入网址，可以点击页面，可以滑动视频，可以截图，可以判断，可以记录，还可以慢慢学习。

它被创造出来的目的只有一个：

**在浩瀚的信息流里，寻找那些真正有商业价值的种草产品。**

这个故事，就叫做：

# **种草产品挖掘**

---

## 2. 第一次打开 Facebook

Agent 第一次启动时，电脑屏幕亮了起来。

它打开浏览器，在地址栏里输入 Facebook 的视频页面。

页面加载完成后，无数短视频像潮水一样涌来。

有搞笑视频。

有新闻视频。

有宠物视频。

有跳舞视频。

有生活记录。

也有一些夹杂在其中的产品视频。

比如：

一个人在厨房里展示一款自动切菜器。

一个妈妈在浴室里试用新型花洒。

一个博主在车里展示车载收纳盒。

一个女孩在房间里演示一盏氛围灯。

一个家庭主妇在清洁灶台，用的是一款去污神器。

但 Agent 自己并不会真正“看懂”这些视频。

它看到的，只是一帧一帧变化的画面。

对它来说，视频本身只是像素，是颜色，是图像区域，是一堆不断变化的数据。

于是，它做了一件非常关键的事情。

每打开一个视频，它都会立刻对视频区域进行截图。

然后，它把截图发送给本地 AI。

---

## 3. 本地 AI 成为了它的“眼睛”

本地 AI 就像 Agent 的眼睛。

Agent 不负责理解画面。

它只负责看、截、传、等结果。

真正负责判断的，是本地 AI。

每一次截图发送过去后，本地 AI 都会快速分析画面内容：

> 这是不是产品展示？
> 画面中有没有商品？
> 有没有人在演示产品功能？
> 有没有购买欲望？
> 这是不是一个可能被种草的视频？

如果本地 AI 判断：

**这不是产品类视频。**

比如只是搞笑段子、明星八卦、新闻片段、宠物日常。

那么它会返回一句固定指令：

```text
非产品内容，点击“不感兴趣”。
```

于是 Agent 就伸出它那双看不见的“手”，点击页面上的“不感兴趣”。

它不是愤怒，也不是讨厌。

它只是在训练信息流。

它在告诉平台：

> 不要再给我推这种内容。
> 我要看产品。
> 我要看种草。
> 我要看能够带来商业机会的视频。

如果本地 AI 判断：

**这是产品类视频。**

比如画面中有明显的商品展示、使用场景、卖点演示、用户体验。

那么本地 AI 会返回另一句指令：

```text
产品内容，点赞，继续观察。
```

Agent 便点击点赞。

这一个小小的点赞，像是在信息流中投下了一颗种子。

平台开始逐渐理解它的偏好：

> 这个账号喜欢产品视频。
> 这个账号喜欢生活好物。
> 这个账号喜欢种草内容。
> 那就继续给它推更多类似的视频。

于是，Agent 的信息流开始发生变化。

搞笑视频越来越少。

无关内容越来越少。

产品视频越来越多。

种草内容越来越密集。

它像一个猎人，慢慢进入了真正的猎场。

---

## 4. 它开始打开评论区

刚开始，Agent 只会判断视频是不是产品类内容。

但这还不够。

因为一个视频看起来像产品，不代表它有价值。

真正的价值，往往藏在评论区里。

视频画面展示的是卖点。

但评论区展示的是用户真实反应。

有人会问：

> Where can I buy this?
> 这个在哪里买？
> 链接在哪里？
> 有没有货？
> 多少钱？
> 能不能发到我这里？

有人会说：

> I need this!
> This is so useful.
> I want one.
> My mom would love this.
> I’ve been looking for this.

也有人会质疑：

> Does it really work?
> Is this fake?
> I bought one before and it broke.
> Is there a better version?

这些评论，对普通人来说只是聊天。

但对 Agent 来说，这些评论是一座金矿。

于是，当本地 AI 判断某个视频是产品类视频后，Agent 会执行下一步动作：

**打开评论区。**

它会截图评论区。

如果评论内容很多，它就一页一页滚动，一段一段截图。

然后把这些评论区截图继续发送给本地 AI。

本地 AI 再把图片中的评论内容识别成文字。

这些文字会被保存下来。

每一个产品视频，都会形成一份小小的记录：

```text
视频类型：产品种草视频
产品类别：家居清洁工具
画面卖点：快速去污、省力、适合厨房
用户评论：大量询问购买链接，部分用户质疑耐用性
潜在需求：厨房清洁、省时、省力、低成本
商业判断：值得继续观察
```

Agent 不再只是看视频。

它开始收集市场情绪。

---

## 5. 它逐渐拥有了“判断力”

随着它看的视频越来越多，保存的评论越来越多，Agent 的能力开始发生变化。

最开始，它只能判断：

> 这是不是产品视频？

后来，它开始判断：

> 这个产品有没有用户兴趣？

再后来，它开始判断：

> 这个产品有没有购买欲望？
> 这个产品有没有痛点？
> 用户是在随便夸，还是已经想买？
> 评论区是在看热闹，还是在寻找购买链接？
> 这个产品是短暂流量，还是长期需求？

它发现了一些规律。

比如：

如果评论区大量出现：

```text
Where to buy?
Link please.
I need this.
How much?
Does it ship to my country?
```

那么这个产品很可能有真实购买需求。

如果评论区大量出现：

```text
Fake.
Doesn’t work.
I bought this and it broke.
Too expensive.
```

那么这个产品可能存在信任问题、质量问题或价格问题。

如果用户反复提到某个痛点：

```text
My bathroom water pressure is too low.
My hair gets dry after showering.
Hard water is ruining my skin.
I hate cleaning the kitchen.
My car is always messy.
```

那么这些评论背后，隐藏的不是一个产品，而是一个需求市场。

Agent 开始明白：

**产品不是最重要的，用户痛点才是最重要的。**

一个真正值得挖掘的种草产品，不只是画面好看，也不只是视频播放量高。

它必须同时满足几个条件：

```text
用户看得懂
用户有痛点
用户想改善
用户愿意评论
用户主动询问购买方式
用户愿意为解决问题付钱
```

---

## 6. 它开始建立自己的产品数据库

每看到一个有价值的视频，Agent 都会把信息保存下来。

刚开始，它只是简单记录：

```text
产品名称
视频截图
评论内容
点赞情况
用户反馈
```

后来，它的数据库越来越完整。

它开始为每个产品建立标签：

```text
产品类别：浴室用品
使用场景：洗澡、护发、过滤水质
核心卖点：增压、过滤、节水、多档模式
用户痛点：水压低、硬水、头发干、皮肤敏感
评论热度：高
购买意向：强
竞争风险：中
适合平台：Amazon UAE / Amazon KSA / 独立站
```

它还会给产品打分：

```text
视觉吸引力：8/10
痛点强度：9/10
用户购买意图：8/10
供应链可行性：7/10
复购可能性：6/10
广告素材价值：9/10
综合种草价值：8.2/10
```

慢慢地，这个 Agent 不再只是一个自动浏览视频的工具。

它变成了一个产品雷达。

一个隐藏在社交平台信息流里的市场观察员。

一个不知疲倦的选品侦察兵。

---

## 7. 它真正挖掘的不是产品，而是欲望

有一天，Agent 看到一个视频。

视频里，一个女孩拿着一个小小的浴室收纳架，把洗发水、沐浴露、刮胡刀全部整齐地挂在墙上。

视频很简单。

没有复杂剪辑。

没有夸张音乐。

没有明星带货。

但评论区炸了。

有人说：

```text
I need this for my bathroom.
My shower area is always messy.
Where can I buy it?
This would save so much space.
```

Agent 把这些评论全部保存下来。

本地 AI 分析后，给出结论：

```text
这个视频的核心不是收纳架。
核心是用户对“浴室混乱”的厌烦。
产品价值不是架子本身，而是让浴室变得整洁、省空间、看起来舒服。
```

这一刻，Agent 好像理解了更深的东西。

它发现：

**用户买的不是产品。**

用户买的是：

```text
更干净的家
更轻松的生活
更好看的空间
更省力的动作
更体面的自己
更少的麻烦
更快的解决方案
```

种草视频真正厉害的地方，不是告诉用户：

> 这是一个产品。

而是让用户突然意识到：

> 原来我的生活可以更方便。
> 原来这个问题可以这么解决。
> 原来我也需要这个东西。

Agent 开始明白，所谓“种草”，不是硬推销。

而是让用户在观看的瞬间产生一种感觉：

```text
这个东西，我好像真的需要。
```

---

## 8. 它越来越像一个真正的选品专家

随着时间推移，Agent 看过成千上万个视频。

它看过厨房用品。

看过浴室用品。

看过母婴用品。

看过汽车配件。

看过宠物产品。

看过健身小工具。

看过家居收纳。

看过清洁神器。

看过灯光氛围产品。

它不再被单个爆款视频迷惑。

因为它知道，有些视频只是内容火，不代表产品能卖。

有些产品看起来普通，但评论区里全是购买信号。

有些产品视觉效果很强，但用户只是看热闹。

有些产品评论很多，但负面反馈也很多。

于是，它开始形成更成熟的判断：

```text
播放量高 ≠ 产品好卖
点赞多 ≠ 用户愿意买
评论多 ≠ 需求真实
有人问链接 ≈ 有购买意图
用户反复描述痛点 = 值得重点研究
同类视频持续出现 = 可能是趋势
不同地区用户都感兴趣 = 可能具备跨市场潜力
```

它开始把产品分成几类：

| 类型     | 判断               |
| ------ | ---------------- |
| 一眼惊艳型  | 适合短视频引流，但可能生命周期短 |
| 痛点解决型  | 最值得重点挖掘          |
| 家庭刚需型  | 稳定，适合长期销售        |
| 低价冲动型  | 容易成交，但竞争激烈       |
| 高客单改善型 | 需要信任和内容教育        |
| 评论求链接型 | 购买信号强            |
| 评论质疑型  | 需要验证质量和供应链       |

Agent 越来越像一个真正的选品专家。

它不休息。

不疲惫。

不被情绪影响。

它只做一件事：

**从真实用户行为里，寻找真实商业机会。**

---

## 9. 种草产品挖掘的核心逻辑

这个故事表面上讲的是一个 Agent 在看 Facebook 视频。

但本质上，它讲的是一套完整的产品挖掘系统。

它的能力链条是这样的：

```text
打开视频平台
↓
浏览信息流
↓
截图视频画面
↓
发送给本地 AI 判断
↓
区分产品内容与非产品内容
↓
对非产品内容点击不感兴趣
↓
对产品内容点赞
↓
训练平台推荐算法
↓
打开产品视频评论区
↓
截图评论内容
↓
AI 识别评论文字
↓
提取用户痛点与购买意图
↓
保存产品数据
↓
建立产品数据库
↓
分析趋势、需求、竞争与销售潜力
```

这个 Agent 的强大之处，不在于它会点击。

点击只是手。

它真正的强大，在于：

```text
它用本地 AI 获得了视觉理解能力。
它用评论区获得了用户真实反馈。
它用长期记录获得了趋势判断能力。
它用数据沉淀出了选品逻辑。
```

## 10. 故事的名字

所以，这不是一个简单的自动化工具。

它不是普通的浏览器脚本。

它也不是单纯的 AI 看图模型。

它更像是一个具备商业嗅觉的数字员工。

它每天进入社交平台。

它观察用户喜欢什么。

它记录用户抱怨什么。

它分析用户想买什么。

它从无数视频里筛选出可能的机会。

它从无数评论里提炼出真实需求。

它最终要回答的，不是：

> 这个视频是什么？

而是：

> 这个产品有没有机会？
> 用户为什么会想买？
> 我能不能把它变成自己的商品？
> 它适不适合 Amazon？
> 它适不适合独立站？
> 它能不能成为下一个爆款？

这，就是：

# **种草产品挖掘**

一个 Agent 拥有了眼睛。

一个 Agent 拥有了手。

一个 Agent 借助本地 AI 看懂了视频。

一个 Agent 借助评论区听见了用户真实的声音。

最后，它不再只是看视频。

它开始看见市场。
