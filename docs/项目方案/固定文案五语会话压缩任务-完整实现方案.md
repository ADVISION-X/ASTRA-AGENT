| 当前 review run 缺失或与任务 identity 不同 | Website 零 root task；重回 prepare，不得在接纳后补造 run |
| root 重复或并发创建 | 读回同一 root |
| 当前 locale 未 admission | 零 successor |
| direct parent/ref/hash 不等 | 零执行、零导航、零提交 |
| 本地 completed 父任务或最终 accepted attempt 缺失 | 停止当前链并移交证据，不跨设备猜测或复制状态 |
| 父 job 同 step WAL 缺失、多义或未 CONFIRMED | typed failure，零 fallback |
| 当前 submit 明确未发生 | Website 依现役法案决定有限新 attempt |
| 当前 submit 已发生或未知 | 同 effect 零 submit 收敛 |
| A/B/Selector 身份或隔离不闭合 | 当前 locale result blocked |
| Provider 限流或上下文上限 | 停止当前链，等待 Website 后续决定 |

| 五次 admission 完成 | 仅进入 import/publish，不直接称 RELEASE |

### 9. 固定文案最终完成判据

固定文案只有同时满足下列条件才算完成：

1. 当前双仓候选及 authority/projection 精确重绑，原生静态验收通过；
2. 五个 locale 各有唯一 task/result、`3C` effect、Website admission receipt 与持久结果 readback；
3. source inventory unresolved=0，catalog 自身从未充当表面证据；总分母为修复后 `3C` conversation、`15C` Provider turn，且无重复现实 submit；
4. 五个任务与唯一冻结 review run 的 source/policy/message/cohort identity 完全一致；candidate-set import 与 publish 使用同一目录成功，catalog/ledger/manifest/runtime projection 一致；
5. Website CHANGE、READY、RELEASE 按原生顺序完成；
6. 部署版本命中，五个 locale 真实页面读取与发布 hash 一致；
7. 核心初心“返本溯源，古为今用”及 `public_value_binding` 在五语公开文案中忠实投影，没有新增 AI/工程价值抢位或事实承诺。

完成前不得使用“已投产”“全链成功”“固定文案已闭环”。
