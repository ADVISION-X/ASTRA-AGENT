四、WHY 文件要求
==================================================

本阶段必须创建或更新 WHY 文档。

建议路径：

docs/why/runtime-debug-transparency.WHY.md

必须包含：

1. Why this exists
- 为什么实战阶段必须 DEBUG 级透明日志
- 为什么 AI prompt / response 必须可追踪
- 为什么只看 summary 会造成大量调试浪费

2. Why not console.log patch
- console.log 不是 proof
- console text 不是 truth
- stdout 不是 Forensics
- debug 必须结构化、可导出、可引用、可执法

3. Why Screenshot prepare-ai-input must be upstream
- AI 不拥有图片压缩
- Screenshot 拥有 ai_input artifact
- AI 只消费合规 aiInputArtifactRef

4. Why AI runtime must log input/output
- prompt contract
- input hash
- raw response
- parser result
- failure envelope

5. Why terminal + forensics double track
- terminal 服务实时调试
- forensics 服务长期追责
- 二者必须同源但不同职责

6. Why enforcement is mandatory
- 日志最容易在修 bug 时被绕开
- 缺执法会回到缝合怪
- 必须 AST 反逃逸

7. Forbidden shortcuts
- direct console.log only
- AI adapter self resize
- Orchestration image manipulation
- map hardcoded compression
- service stdout as truth
- prompt hidden behind length only
- response hidden behind summary only

==================================================
五、实现标准
==================================================

1. Log levels

必须支持：
- ERROR
- WARN
- INFO
- DEBUG
- TRACE 可选

环境变量：
- GRASSEYE_LOG_LEVEL=debug
- GRASSEYE_DEBUG_AI_IO=summary | full
- GRASSEYE_DEBUG_BUNDLE=on | off
- GRASSEYE_DEBUG_TERMINAL_JSON=compact | pretty

2. Terminal DEBUG

当 GRASSEYE_LOG_LEVEL=debug 时，终端必须看到：
- runtime debug event
- action debug event
- AI request debug event
- AI response debug event
- AI error debug event
- screenshot handoff debug event
- service exit debug event

3. AI IO

summary 模式：
- promptHash
- promptPreview
- promptLength
- promptContractId
- image refs/path/hash/size/dimensions
- rawResponseHash
- responsePreview
- parsedDecision

full 模式：
- full system prompt
- full user prompt
- full raw response text
- parsed JSON
- parser errors

禁止：
- full 模式也不得输出 base64 image
- 不得泄漏 cookies / tokens / secrets
- redaction policy 必须存在

4. AI input preflight

在 AI runtime request 前必须执行：
- image size check
- image dimensions check
- mime check
- aiInputArtifactRef check
- prompt contract check
- model capability check

如果失败：
- 不得调用模型
- 记录 AI_ERROR_DEBUG
- 生成 governed failed / review_required
- 指向 responsible owner
- 指向 missing upstream step

5. prepare-ai-input contract

AI vision step 输入必须为：
- aiInputArtifactRef
- imageHash
- imageBytes <= model limit
- sourceScreenshotEvidenceId
- scaleMapping
- producedBy = screenshot.prepare-ai-input

不得直接消费：
- original oversized screenshot
- raw video screenshot artifact
- arbitrary file path

6. Service exit transparency

app_server unexpected_exit 必须记录：
- exitCode
- signal
- pid
- startedAt
- endedAt
- lastRuntimeEventId
- lastAiEventId
- lastRoundId
- lastStepId
- likelyCauseRef
- crashBundleRef

六、执法系统要求
==================================================

必须使用 ts-morph。
必须 AST 级、symbol 级、reference 级、alias 级、anti-escape。
禁止用 grep / regex / includes / match / split 作为最终结构判断。

├── inspector.ts
├── required-shape.ts
├── forbidden-shape.ts
├── boundary-attack.ts
├── anti-escape.ts
├── negative-proof-harness.ts
└── ast-utils.ts

Required Shape 必须检查：
- RuntimeDebugEventSchema exists
- AiRequestDebugEvent exists
- AiResponseDebugEvent exists
- AiErrorDebugEvent exists
- TerminalStructuredLogRelay supports DEBUG
- DebugBundleWriter exists
- AI request path emits AiRequestDebugEvent before model call
- AI response path emits AiResponseDebugEvent after model call
- AI error path emits AiErrorDebugEvent before terminal failure
- AI input preflight exists before model call
- prepare-ai-input output is required for vision AI
- service unexpected_exit emits structured debug event
- WHY file exists

Forbidden Shape 必须检查：
- console.log as only debug mechanism
- promptLength only without promptHash/ref/full mode
- rawResponse hidden completely
- AI adapter self resize without Screenshot
- Orchestration image resize/compress
- map hardcoded compression
- direct file path into AI vision without aiInputArtifactRef
- model call before AI input preflight
- oversized image model call
- service exit without debug event
- debug event without mission/round/step refs
- full mode outputting base64 image
- secrets/cookies in terminal debug
- generated debug success without forensics ref

Boundary Attack 必须检查：
- Screenshot owns prepare-ai-input
- AI owns model request/response logging
- Forensics owns persisted debug refs
- Terminal relay only displays events
- Orchestration only dispatches steps
- Map only declares dependency
- No owner bypass

Anti-Escape 必须检查：
- alias laundering model call before preflight
- wrapper hiding direct AI file path call
- barrel laundering console.log patch
- fake debug event not connected to runtime proof
- prompt hidden in closure with only length logged
- raw response swallowed by parser
- error thrown before AiErrorDebugEvent
- image size failure thrown without ownerResponsible
- prepare-ai-input bypass through direct artifact path
- service SIGTERM swallowed without structured event
