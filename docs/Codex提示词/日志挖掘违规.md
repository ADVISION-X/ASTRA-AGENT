四、金字塔根因挖掘模式
==================================================

必须按金字塔分析，不得平铺罗列。

输出结构：

Root Layer 0：实战目标
- 系统应该透明运行。
- AI 投喂内容、模型、图片、prompt、response、解析、失败都应该可追踪。
- 终端必须看到 DEBUG 级别核心信息。
- Forensics 必须保存可追责结构化事件。

Layer 1：最源头问题
必须判断当前最源头问题属于哪类：

A. 日志透明化不足
B. Map step dependency 错误
C. Screenshot prepare-ai-input 没进入 AI 前置链
D. AI runtime 只在执行时拒绝大图，缺前置 preflight
E. Forensics / runtime log 缺 AI prompt/response 证据
F. Orchestration step 没有强制输入 contract
G. 旧 runtime chain 绕过能力组标准包
H. terminal relay 只转摘要，不转 DEBUG detail
I. service SIGTERM 是异常退出症状，不是根因

Layer 2：第二层问题
必须找出：
- 哪些 owner 没履职
- 哪些 owner 越权
- 哪些 proof 缺失
- 哪些日志缺失
- 哪些 step dependency 缺失
- 哪些 failure 被推迟到太晚才发现
- 哪些字段只出现在文本里，没有结构化

Layer 3：第三层问题
必须继续细化：
- 缺少哪个 gate
- 缺少哪个 proof field
- 缺少哪个 read model
- 缺少哪个 artifact ref
- 缺少哪个 hash
- 缺少哪个 timeout / abort / size budget
- 缺少哪个 terminal event
- 缺少哪个 structured debug bundle

Layer 4：证据
每一个问题必须绑定：
- log evidence
- code evidence
- law evidence
- construction blueprint evidence
- uncertainty level

不得写“可能是”后不继续追踪。
如果证据不足，必须写：
- UNKNOWN
- missing evidence:
- next read-only scan:

==================================================
六、四方攻击：分析阶段也必须自检
==================================================

本阶段虽然不改代码，但分析必须防漂移。

A. Required Shape Attack
必须确认分析覆盖：
- startup
- terminal log relay
- runtime structured event
- action log
- forensics record
- AI request
- AI response
- AI error
- screenshot prepare-ai-input
- orchestration map dependency
- service exit

B. Forbidden Shape Attack
分析不得：
- 直接跳到修复
- 只说“加日志”不找根因
- 把 SIGTERM 当唯一根因
- 把图片过大当唯一根因
- 忽略 prepare-ai-input owner
- 忽略 map dependency
- 忽略 AI prompt/response 不透明
- 忽略 terminal vs forensics 双轨日志
- 忽略执法系统

C. Boundary Attack
必须确认：
- 日志透明化不改变 owner 主权
- AI 日志不让 AI owner 越权截图
- Screenshot prepare-ai-input 仍归 Screenshot
- Orchestration 只调度，不处理图片
- Forensics 只落盘，不生成 AI 决策
- Terminal relay 只转发，不制造 truth

D. Anti-Escape Attack
必须防止：
- 用 console.log 临时补丁代替结构化日志系统
- 用 debug 文本代替 owner evidence
- 用 AI adapter 自己压缩图片绕过 Screenshot
- 用 map 里硬编码图片压缩绕过 Screenshot
- 用 local_ai_decision 旧链路绕过 AI 能力组
- 用 service stdout 作为唯一日志源
- 用 grep 查日志代替 structured event
