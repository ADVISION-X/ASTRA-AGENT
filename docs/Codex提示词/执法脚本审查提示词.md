Step 3：深化 inspector
------------------------------------------------

每个 lawId 必须有真实检查。

每个 inspector 必须覆盖四方攻击：

1. Required Shape Attack
   - 必须存在的 route / component / function / DTO / boundary / call graph / JSX / import / export / runtime seam 是否真实存在。

2. Forbidden Shape Attack
   - 禁止的 route / folder / import / mock / fake / fixture / fallback / direct access / local truth / raw shape / old owner 是否不存在。

3. Boundary Attack
   - 其他 owner 是否抢权。
   - route / UI / util / lib 是否绕过当前 owner。
   - 总调度是否吞并子能力。
   - 总司令是否执行 runtime 细节。
   - 子契约是否重新变成独立 owner。

4. Anti-Escape Attack
   - any
   - unknown as
   - ts-ignore
   - ts-expect-error
   - eslint-disable
   - dynamic import
   - require
   - barrel export
   - re-export
   - alias laundering
   - wrapper hiding
   - fallback success
   - no-op pass
   - warning-only pass
   - generated 手工漂移

必须使用：

- ts-morph Project
- SourceFile
- SyntaxKind
- TypeChecker
- Symbol
- AliasedSymbol
- ImportDeclaration
- ExportDeclaration
- CallExpression
- JsxElement
- PropertyAccessExpression
- findReferencesAsNodes

允许 fs / glob 枚举文件。
禁止 fs 文本扫描作为 TypeScript/TSX 结构判断依据。
