```txt
local 法案的内容有价值；

```

它们应该被合并到：

```txt
AI

Page State

```

```txt
基础层 + 14 能力组 + Map Plugin 支撑治理 + 施工图
```

不要再让 local 细节成为一堆独立法案。


这就是你说的“不单纯”。
现在应该瘦身，把 local 全部重新归属。
